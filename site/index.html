golded

A message reader for the terminal.

Read and write FidoNet echomail and netmail across six message-base formats. Area list, message list, thread tree, quoting replies, two DOS-era themes.

00

Install

Install from PyPI with Python 3.12 or newer, as a tool with its own environment:

uv
uv tool install golded
golded --help
pipx
pipx install golded
golded --help

The command is golded; the package and import name are also golded. It runs on Linux, macOS and Windows; CI tests all three, and on Windows only headless.

01

First run

By default, golded looks for messages.sqlite3 and golded.toml in the current directory.

open a base
golded --database messages.sqlite3

To open areas across bases, use the TOML area table or a classic AREADEF configuration. Use --readonly to browse with writes disabled.

The splash screen counts down from 10 (splash_seconds in golded.toml); any key skips it. Pick an area with ↑ ↓ and Enter, open a message, and step with ← →. Esc goes back one screen and quits from the area list. Set your name and address in golded.toml before you write.

02

New in 1.1.0

GoldED opens JAM, Squish, FTSC MSG, Opus and Hudson alongside SQLite. You can read messages, compose new ones and reply. A single configuration can mix formats.

Use --readonly and --debug to browse and report on existing bases. Squish read and write modes handle older bases that need more permissive reading or appends.
