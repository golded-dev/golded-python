Message bases.

What a base is, how to make one with ftnt, and the demo base for working on golded itself.

00

What golded opens

A SQLite message base is one file in the golded-ftn-sqlite format. It holds one or more areas; each area is echomail or netmail and has a code (GENERAL) and a display name. golded lists the areas, reads their messages and appends the messages you write. It does not delete, edit or toss messages.

For JAM bases, see AREADEF configuration.

Close the base in other programs while golded writes to it. A read-only file can still be read; saving then fails with a message in the status bar, and the draft stays open.

01

Make a base with ftnt

ftnt from golded-ftn-tools 1.2.0 creates a base with one area and appends messages from JSON:

create a base with one echomail area
uvx --from golded-ftn-tools==1.2.0 ftnt create messages.sqlite3 \
  --format sqlite --area GENERAL --area-name 'General chat' --origin 2:236/777
append one message
echo '{"from_name":"Alice","to_name":"All","subject":"Hello","body_text":"First post.\n","posted_at":"2026-11-14T10:00:00"}' \
  | uvx --from golded-ftn-tools==1.2.0 ftnt write messages.sqlite3 --format sqlite

--kind netmail makes a netmail area instead. Then open it with golded --database messages.sqlite3.

02

Demo base for contributors

A checkout has scripts/seed_demo.py, which builds the base the tests and screenshots use: six areas covering an empty area, one message, a gap in message numbers, a long message, a thread and netmail. Its Faker seed is fixed, so the content is the same every time.

in a checkout
uv sync
uv run python scripts/seed_demo.py
uv run golded

It deletes first. The seeder removes messages.sqlite3 and its -wal and -shm files before writing. Do not run it next to a base you want to keep.

03

When it will not open

Startup problems print one line on stderr and exit with status 1.

SituationMessage
No file at the pathDatabase not found: PATH, then a hint
Not an SQLite fileCannot open database PATH: file is not a database
SQLite, but another schema or versionCannot open database PATH: not a supported golded-ftn-sqlite database
Directory not writableCannot open database PATH: attempt to write a readonly database
