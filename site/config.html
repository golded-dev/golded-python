Configuration.

One TOML file and three options. Product name and version are fixed in the code.

00

golded.toml

TOML in the current directory, or the path given with --config. A missing file means defaults. Every field is optional.

golded.toml.example
# Copy to golded.toml and edit.
# Used when you start the app and when you write or reply.

from_name = "Odinn"
from_address = "2:236/777"
database = "messages.sqlite3"
origin = "Where we're going, we don't need roads."
theme = "dark"
threaded_list = false
splash_seconds = 10
01

Fields

FieldDefaultMeaning
from_nameemptyYour name, filled in when you write or reply. Saving needs a From name.
from_addressnoneYour FTN address, such as 2:236/777. Used in From and the Origin line.
databasemessages.sqlite3The message base to open.
originWhere we're going, we don't need roads.Text of the * Origin: line below the tearline.
themedarkdark or light.
threaded_listfalseStart the message list as a thread tree. A TOML boolean; t toggles it in the app.
splash_seconds10How long the splash screen counts down. A whole number; 0 skips the splash.
02

Command-line options

Options override the file.

OptionDefaultMeaning
--config PATHgolded.tomlUser config file
--database PATHfrom config, else messages.sqlite3SQLite message base
--theme NAMEfrom config, else darkdark or light
03

Invalid values

A config golded cannot use stops it at startup with Cannot read config PATH: … and exit status 1: malformed TOML, an invalid from_address, an unknown theme, a threaded_list that is not true or false ("no" is a string, and an error), or a splash_seconds that is not a whole number of 0 or more.
